Ripple Index Scale
70–100 — Strong ripple
30–69 — Moderate ripple
1–29 — Fading ripple
0 — Absorbed (back to baseline)
Trend Labels
↑ Spiking — still climbing toward peak
→ Plateau — holding near peak
↓ Fading — declining from peak
↓ Absorbed — near baseline, ripple over
Mockup notes: This is a static HTML mockup showing the Ripple Index concept. Each event gets a 0–100 score based on how far above baseline each lane currently is, relative to the peak lift observed since the event. The ring color shifts from green (strong) → yellow (moderate) → red (fading) → gray (absorbed). The decay sparkline shows the ripple curve over time with the event marker. The dashboard row gives a quick "wake up and glance" summary of all active ripples.
